---
name: task-manager
description: 在 OpenCode 中打开本机定时任务管理页面。用户说“打开定时任务管理”“管理定时任务”“查看计划任务”时使用；页面可创建、编辑、暂停、删除、立即执行及查看历史。
---

调用当前项目的 `open_task_manager` 工具打开浏览器页面。成功后告知用户页面已打开。
如果工具缺失，说明当前 OpenCode 项目尚未加载 Workbench 插件，指向项目 README 的安装方法；不要启动第二个 OpenCode 后端或猜测端口。

工具只打开页面。不要代替用户创建任务、立即执行、批准工具操作或发送飞书消息，除非用户另外明确要求。
鉴权链接只供本机页面使用；不要将链接或令牌发到飞书、外部消息、日志或公开文档。
说明任务随 OpenCode 后端运行：真正退出、睡眠或关机时不能准点执行，恢复后按任务补跑策略处理；不声称后台常驻或精准唤醒。
等待审批、等待回答或结果待确认时，引导用户在 OpenCode 的对应专属会话处理；不要把“已提交”或“session.idle”单独视为成功。
