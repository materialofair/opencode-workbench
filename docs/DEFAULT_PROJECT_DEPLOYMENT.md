## 当前使用与回滚

现在可从 Default Project 的会话中让 Skill 打开管理器。原有默认模型的连接故障没有被改写；若新会话仍选中该不可用路由，应在会话中选用已有可用模型。任务也可以在「本任务模型」指定已有路由，留空则沿用宿主默认。

回滚只删除安装器拥有且内容匹配的两个文件：

```sh
bun scripts/install.ts --project "/absolute/path/to/Default Project" --remove
bun scripts/install.ts --project "/absolute/path/to/Default Project" --remove --apply
```

在其他工作结束后再重建该目录实例，以卸载内存中的插件；不要在有飞书或其他进行中工作时退出整个 Desktop。卸载不删除任务库、历史、模型或飞书配置。
