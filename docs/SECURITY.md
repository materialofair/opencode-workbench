# 安全与隐私边界

管理页面仅监听 127.0.0.1 的随机端口，不提供外网、局域网或飞书内嵌访问。随机 256-bit capability 经 URL fragment 送到默认浏览器；fragment 不进入 HTTP 请求，页面立即清除地址栏并在本 tab sessionStorage 保存授权。插件重新加载即轮换 token。工具不会把链接返回给模型、聊天或飞书；如无法打开浏览器，会报告错误。

所有 API 需要 Authorization。写请求同时要求精确 Origin 和 X-Task-CSRF。拒绝其他 Origin、跨站 Sec-Fetch-Site 和伪造 Host；没有 CORS。采用 CSP、frame-ancestors none、nosniff、no-referrer、no-store，静态资产限定白名单，最大请求体 64 KiB。React 文本渲染用户内容，不渲染模型 HTML。没有任意文件读取、命令执行、宿主代理、权限回复或飞书发送 API。

前端能看到本人输入的任务指令、项目路径、会话 ID 和有限运行元数据。它不会取得宿主 Authorization、服务端密码、模型配置、模型回复、飞书 appSecret 或私有对话历史。运行错误存通用提示，详情由用户在 OpenCode 查看。SQLite 权限与目录按本机用户收紧；任务指令本身可能包含敏感信息，不能放入公开仓库。页面 token 本身同样应保密；不要共享页面链接、DevTools/网络日志或 runtime 文件。

每个任务建立新会话：默认 ask，并保留全局与选定 Agent 中的 deny。页面没有批准按钮。普通宿主事件传入后只更新此插件已记录的 sessionID，不接管飞书或其他会话。当前插件不改变其他插件/宿主的安全设定；如果宿主自动批准模式、其他插件、MCP 服务或自定义工具绕过原生权限机制，插件无法为其补上完整沙箱。此类执行环境不应安排外部副作用任务。不要把定时触发视为对所有后续行为的无限授权。

对未确认的模型或网络提交不自动重试；幂等 slot、同任务互斥、租约和重启核对减少重复提交，但不能宣称跨外部系统 exactly-once。拒绝审批/取消可能仍留下已发生的操作。任务创建者应在指令中明确允许的操作范围。

飞书为可选、独立入口。本地源码不包含真实配置；构建适配不读取配置或连接机器人。新适配的 Langfuse 用户 trace 需显式环境变量开启；沿用的上游内容日志仍可能含消息元数据，因此不要公开运行日志。不要同时加载既有飞书入口和新增副本。

Windows 仅收紧插件自己的项目状态目录 ACL，不改变全局权限、execution policy 或防火墙；失败则不启动调度。POSIX 使用私人目录/文件权限。安装器拒绝经过符号链接或 Windows junction 写入目标，以避免越出选定安装位置。完整平台范围见 [Windows 说明](WINDOWS.md)。

`bun run scan` 为启发式公开文件扫描，`bun run scan:release` 另扫描全部本地 Git 对象、历史路径及提交元数据；两者不覆盖所有未知密钥格式，也不代替依赖漏洞审核或人工检查。

原锁文件的 5 个 high 节点已通过精确覆盖 Zod/TOML 叶子依赖消除，新锁文件干净安装的 npm audit 为 0；未替换宿主内置依赖或用户现用安装。逐项可达性、兼容测试与修复范围见 [依赖安全核查](DEPENDENCY_SECURITY.md)。
